# 도서관 탐험대

초등학생이 가상의 학교도서관을 직접 돌아다니며 도서 검색 → 청구기호 확인 → 서가 찾기 → 책 찾기 → 대출까지 경험하는 웹 기반 도서관 이용교육 프로그램입니다.

## 실행 방법

설치할 것이 없습니다. `index.html` 파일을 크롬이나 엣지 브라우저로 열면 바로 시작됩니다.
(수업에서 여러 학생이 쓰려면 폴더 전체를 학교 웹 서버나 공유 폴더에 올려 두세요.)

- 서버, 데이터베이스, 로그인이 없습니다.
- 학생 이름과 탐험 기록은 브라우저 탭이 열려 있는 동안만 저장되고, 탭을 닫으면 지워집니다.
- 인터넷이 없어도 동작합니다. 인터넷에 연결되면 글꼴(Noto Sans KR)만 추가로 불러옵니다.

## 교사용: 점검 모드

`점검모드.html`을 열면 이름 입력 없이 도서관으로 바로 들어가고, 화면 왼쪽 아래에 **🛠 점검 도구**가 나타납니다.

- 순서 잠금이 꺼져 어느 탐험이든 바로 열 수 있습니다.
- 탐험마다 도장을 주거나 지울 수 있고, 도장 모두 받기·기록 지우기, 종합 미션·완료 화면 바로 가기를 쓸 수 있습니다.
- 새로고침(F5)해도 진행 상태가 남아 있습니다. 탭을 닫으면 지워집니다.
- 학생에게는 `index.html`을 주세요. 학생 화면에는 점검 도구가 나타나지 않습니다.

## 교사용: 내용 고치기

코드를 몰라도 `data` 폴더의 세 파일을 메모장이나 편집기로 열어 문구를 바꿀 수 있습니다.
따옴표(`'...'`)와 쉼표 형식을 지켜 주세요.

| 파일 | 고칠 수 있는 내용 |
| --- | --- |
| `data/books.js` | 가상 도서 목록(제목, 저자, 출판사, 청구기호, 주제어, 대출 상태, 표지 색·그림). 검색 결과와 서가의 책이 함께 바뀝니다. |
| `data/missions.js` | 각 활동의 질문, 힌트, 완료 문구, 검색 미션 낱말, 종합 미션 쪽지, **대출·반납 규칙(학교별로 수정)** |
| `data/classifications.js` | 000~900 서가 이름, 설명, 예시 주제, 색 |

자주 고치는 곳:
- 우리 학교 대출 규칙 → `missions.js`의 `loan.rules`, `loan.schoolNote`, `loan.loanDays`
- 검색 미션 → `missions.js`의 `search.missions` (학생마다 이 중 하나가 무작위로 나와요. `bookIds`의 책 가운데 ‘대출 가능’인 책을 골라 기억하면 돼요. 점검 모드의 🔎 검색 미션 바꾸기로 하나씩 확인할 수 있어요)
- 종합 미션 낱말 → `missions.js`의 `final.keyword` (예: '우주'). 이 낱말이 `keywords`에 들어 있고 대출 가능한 책이 `books.js`에 있어야 합니다.
- 서가에서 찾을 책 → 학생이 검색 미션에서 기억한 책이에요

## 도서관 공간과 활동

| 도서관 속 장소 | 활동 | 탐험 도장 |
| --- | --- | --- |
| ① 이용 안내판 | 지켜야 할 행동 카드 고르기 | 도서관 이용 |
| ② 신간도서 진열대 | 책을 돌려 가며 제목·글쓴이·출판사·책등·라벨 찾기 | 책 정보 |
| ③ 책 수레 | 서가 설명(? 단추)을 보고 책을 알맞은 분류 서가로 옮기기 | 분류번호 |
| ④ 청구기호 포스터 | 라벨의 각 부분 뜻 알아보기, 800 서가 청구기호 고르기 | 청구기호 |
| ⑤ 열람 테이블 책꽂이 | 청구기호 순서대로 책 꽂기(3단계) | 책이 꽂힌 순서 |
| ⑥ 도서검색대 | 학생마다 무작위로 받은 검색 미션(제목·저자·주제 검색)으로 책을 찾고 청구기호 기억하기 | 도서 검색 |
| ⑦ 분야별 서가(000~900) | 검색 미션에서 기억한 책을 청구기호로 서가를 골라 찾기 | 책 찾기 |
| ⑧ 대출·반납대 | 입장할 때 쓴 이름의 도서 대출증을 먼저 찍고 책 대출하기, 반납하기 (대출·반납 과정을 짧은 애니메이션으로 보여 줘요) | 대출·반납 |

- 탐험은 번호 순서대로만 열립니다. 앞 탐험을 끝내야 다음 탐험에 들어갈 수 있고, 끝낸 탐험은 언제든 다시 할 수 있습니다.
- 순서는 `missions.js`의 `LIBRARY_MISSION_ORDER`에서 바꿀 수 있습니다.
- 순서 잠금을 끄고 자유 탐험으로 쓰려면 `missions.js`의 `LIBRARY_STRICT_ORDER`를 `false`로 바꾸세요.
| 게시판 | 도장 8개를 모으면 종합 미션(검색부터 대출까지) 열림 | 종합 미션 |

- 점수가 없고, 틀려도 다시 시도할 수 있습니다. 모든 주요 활동에 단계별 힌트가 있습니다.
- 끌어다 놓기가 어려우면 책을 누른 다음 놓을 곳을 누르면 됩니다(키보드로도 조작할 수 있습니다).

## 파일 구성

```
index.html                 시작 파일
css/style.css              디자인
js/app.js                  화면과 동작
data/books.js              가상 도서 목록
data/missions.js           활동 내용
data/classifications.js    분류 서가 정보
```

그래픽은 모두 CSS와 SVG로 직접 그렸고, 실제 도서 표지나 다른 사이트의 디자인은 쓰지 않았습니다. 책과 저자, 출판사는 모두 가상입니다.
